# 3-1 Semester - Module 1 Hands-On 1

## 🤖 Pulse AI - Android AI Assistant

Pulse AI is a modern AI-powered Android application developed as part of **3-1 Semester, Module 1 - Hands-On 1**.

The application demonstrates how to build a professional mobile user interface and connect an Android application with an AI API.

## ✨ Features

- Modern dark-themed AI interface
- Real-time AI-generated responses
- Groq API integration
- Quick prompt suggestions
- User and AI message interface
- API error handling
- Responsive mobile UI

## 🛠️ Technologies Used

- Kotlin
- XML
- Android Studio
- Groq API
- OkHttp
- REST API
- JSON

## 📱 Project Objective

**Setup & UI Lab**

- Setup the mobile development environment
- Build a basic and professional mobile UI
- Connect the mobile application with an AI API
- Display AI-generated responses in the application

## 🚀 How to Run

1. Clone this repository.
2. Open the project in Android Studio.
3. Configure your own Groq API key.
4. Sync the Gradle files.
5. Build and run the application on an emulator or Android device.

## 🔐 Security Note

Do not upload API keys directly to GitHub. Use your own API key and keep sensitive credentials outside the public source code.
